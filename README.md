# Trivia Board

A quiz-board game for hosting trivia with 2–5 teams. It is a static site with no server or build step.

## Hosting on Render

`render.yaml` defines a free Render static site. In the Render dashboard choose **New → Blueprint**
(or **New → Static Site**: publish directory `.`, build command left empty) and connect this repo.
Every push to `main` redeploys. To try it locally, run `python3 -m http.server` in this folder and
open http://localhost:8000 (YouTube clips need a web address; they won't play from a local file).

## Making a board

**New board** builds a complete board in one click (two rounds plus a final) and opens it in the
editor. Every category runs easiest at the top to hardest at the bottom. From there you only tweak:

- **Categories** – swap one for a fresh category, reorder, remove, rename, or add another.
- **Clues** – click a clue to rewrite it, swap it, move it up or down, or remove it. Drag one clue onto
  another to trade places.
- **Undo** steps back through your changes; everything saves automatically.
- **Mix settings** – choose hand-written categories, the open bank, or both; the number of rounds; and
  which topics are in play (Holiday is off by default). "Regenerate" rebuilds the whole board.
- **Find a clue** – search every clue by keyword, category and difficulty, then "Use" it or make a
  themed category from the matches.

Boards are saved in the browser (localStorage). **Export** gives copyable text and **Import board**
restores it on any device.

### Picture clues

Select a clue in the editor and either paste an image address into "Picture" or press **Upload
picture** to use a file from your computer. Uploads are shrunk to at most 1600 px and kept in this
browser (IndexedDB), so they don't fill up the space boards are saved in. The picture shows above the
clue text on the host and guest screens; the clue text can be short ("Name this national park").
Exports include uploaded pictures, so a board with pictures is easiest to move with **Save as file**.
Ready-made boards can also use pictures stored in this repo under `images/`.

## Playing

- **Rounds** – six categories of five clues worth 200–1000. Round 2 is worth double, round 3 triple.
- **Wildcards** – hidden clues (two per round by default; set 0–3 when you start a game) where only
  the team that picked it plays, for a wager of its choosing.
- **Final wager** – every team wagers up to its score on one last clue.
- **Scoring** – the host marks each team ✓ or ✗ on a clue. Click any score to correct it by hand.
  Space reveals the response; Esc closes a clue. A game in progress survives a page refresh.

### Host screen and guest screen

Open the page in two windows of the same browser. In the second one press **Guest screen** on the home
page (or add `#screen` to the address) and project or share that window. It follows the host's game
and shows a response only once the host reveals it, while the host window shows every response in a
"Host only" box. **Full screen** (button or F) is on both screens; the host screen always hides
responses while it is full screen, and "Responses: shown here / hidden" (or H) toggles them any time. Untick "Show responses on this host screen" before starting if you only have one
screen. Both windows must be in the same browser on the same computer.

## Clues

`curated.js` holds the hand-written categories (five clues each, ordered easy to hard) and final
clues. Add your own by following the same shape. A clue can carry an optional third item, a clip link (also editable in the editor).
YouTube links play inside the clue when the game is served from its own website: on the guest screen
when one is open, otherwise on the host screen. Add `&t=90` (or `t=1m30s`) to start the clip there and
`&end=110` to stop it. Inside a claude.ai artifact or a local file, clips open in a new tab instead.

### Open bank

`clues.js` is generated by `build_bank.py` from the [Open Trivia Database](https://opentdb.com)
(CC BY-SA 4.0). Each question is reworded by rule into a statement clue with a question-form response;
questions the rules can't convert cleanly are left out. The reworded clues are an adaptation shared
under the same licence.

```bash
python3 build_bank.py fetch raw.json    # ~10 min, the API is rate-limited
python3 build_bank.py build raw.json    # rewrites clues.js
python3 build_bank.py sample raw.json   # eyeball 60 random before/after pairs
```
